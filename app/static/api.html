Public read-only API

Read-only access. Limit: 180 requests per minute per IP. Amounts are decimal strings; amount_raw is in nGNK. Period hours: 1–168. Pagination: limit ≤ 200 and offset. Full coverage of the selected period is not promised.

Overview and archive

GET /api/overview?hours=24

Source status, exact aggregates, coverage, archive and period_complete. Every time-based API accepts since — the start in Unix seconds, taking priority over hours. For example, since=1780779600 means from June 7, 2026 00:00 MSK. The filter does not mean the whole period is already loaded. Balances and snapshots are not rewound to that date.

Events

GET /api/events

Filters: hours, kind, chain, address, minimum (whole GNK), limit, offset. kind accepts a comma-separated list.

Bridge

GET /api/bridges?hours=24

Routes, both sides of a transfer and the matching evidence. Parameters: limit, offset.

Hosts and rankings

GET /api/hosts

/api/rankings?mode=sell&hours=24. mode: buy, sell, rewards, unlocks.

Wallet and address history

GET /api/wallet/{address}?hours=24 — current balance and up to 100 events. GET /api/addresses/{address}?hours=0&kind=trades&limit=50&offset=0 — all pages of local history. For addresses, hours=0 removes the time filter; kind: trades or all.

Holders

GET /api/holders?asset=GNK

asset: GNK or WGNK. Default minimum=10000 tokens; 0 means all positive balances. Filters: q, tag (buy, sell, both, none), hours, limit, offset. The response includes census progress and the balance time. hours=0 is supported.

Live and export

GET /api/export.csv

/api/stream — SSE with a revision number every 5 seconds. /healthz — application health, not a guarantee of RPC sync.
