Публичный read-only API

Доступ только на чтение. Лимит: 180 запросов в минуту на IP. Суммы — десятичные строки; amount_raw в nGNK. Период hours: 1–168. Пагинация: limit ≤ 200 и offset. Нет обещания полного покрытия выбранного периода.

Обзор и архив

GET /api/overview?hours=24

Состояние источников, точные агрегаты, coverage, archive и period_complete. Во всех временных API можно передать since — Unix-секунды начала, с приоритетом над hours. Например, since=1780779600 — с 07.06.2026 00:00 МСК. Фильтр не означает, что весь период уже загружен. Балансы и снимки не перематываются на эту дату.

События

GET /api/events

Фильтры: hours, kind, chain, address, minimum (целые GNK), limit, offset. kind допускает перечень через запятую.

Мост

GET /api/bridges?hours=24

Маршруты, обе стороны перевода и основание сопоставления. Параметры limit, offset.

Хосты и рейтинги

GET /api/hosts

/api/rankings?mode=sell&hours=24. mode: buy, sell, rewards, unlocks.

Кошелёк и история адреса

GET /api/wallet/{address}?hours=24 — текущий баланс и до 100 событий. GET /api/addresses/{address}?hours=0&kind=trades&limit=50&offset=0 — все страницы локальной истории. Для addresses hours=0 снимает временной фильтр, kind: trades или all.

Держатели

GET /api/holders?asset=GNK

asset: GNK или WGNK. По умолчанию minimum=10000 токенов; 0 — все положительные балансы. Фильтры q, tag (buy, sell, both, none), hours, limit, offset. Ответ содержит прогресс переписи и время балансов. Поддерживается hours=0.

Live и экспорт

GET /api/export.csv

/api/stream — SSE с номером ревизии каждые 5 секунд. /healthz — работоспособность приложения, не гарантия синхронизации RPC.
