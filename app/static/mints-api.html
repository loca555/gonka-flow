API монитора WGNK

Только чтение. В APP_MODE=mints старые API полного режима отключены. GNK не опрашивается.

  • /api/mints?minimum=0 — все сохранённые финальные выпуски, 50 строк на страницу.
  • Фильтры: minimum, hours, q (hex-адрес получателя, хеш или request ID), finality=finalized|all.
  • sort: newest, oldest, largest либо time, recipient, amount, tx, status с суффиксом _asc или _desc. Сортировка всей выборки выполняется до limit/offset.
  • /api/mints/tx/{tx_hash} — выпуски одной транзакции.
  • CSV всех выпусков — до 50 000 строк, без молчаливого усечения; поддерживает те же фильтры и сортировку.

amount_raw — точная целая строка nWGNK, amount — десятичная строка (9 знаков). ts — Unix UTC; time_local — ISO со смещением, timezone = Asia/Nicosia. Дневные агрегаты учитывают летнее/зимнее время.

coverage содержит реальные обработанные интервалы, блок создания контракта и финальный блок. Предварительные события не входят в итоги по умолчанию.

Пулы, покупки и продажи

/api/mints/flows?side=sell, side=buy — покупки. hours и q независимы от порога чеканки. Полный адрес требует подтверждённого оттока/притока WGNK у инициатора receipt; остальные hex-запросы ищут хеши транзакций.

sort: time, actor, amount, quote, price, pool, tx с суффиксом _asc или _desc; по умолчанию time_desc. Параметры limit/offset применяются после сортировки. Цена сравнивается как точное отношение целых чисел.

trades — выбранная сторона обменов, summary.volume — её оборот. Поле sales для совместимости содержит только продажи, при side=buy оно пустое. sold и bought не смешивают стороны. Все торговые агрегаты включают все адреса двух проверенных пулов, не только получателей чеканки.

minters — отдельный отчёт по адресам, получавшим WGNK при выпуске, и их продажам за всю историю. Он не зависит от side/hours/q. Продажи могут включать впоследствии купленные токены: индивидуальные партии не отслеживаются.

ready=false означает отсутствие сверенного снимка, а не нулевые показатели. snapshot задаёт единый финальный блок и сверку totalSupply / balanceOf с полной историей.

Цена продажи = USDT на выходе / WGNK на входе пула; цена покупки = USDT на входе / WGNK на выходе. Отображаемые цены округлены вниз до 12 знаков, без газа и возможных комиссий маршрутизатора. Оборот повторяемый, не доля уникальной эмиссии. Переводы и ликвидность не считаются покупками/продажами. Другие DEX, CEX и OTC не покрыты.
